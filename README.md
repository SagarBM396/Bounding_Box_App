# The Bounding Box App

This is an android application that can be used to annotate images for a Computer Vision training dataset. Users can either capture a photo or load an image from gallery or file system into a canvas.
They can annotate the image on the canvas by drawing various shapes around the object they are annotating, and enter a label. For example, in an image of a car, the users can annotate a wheel or a door.
These annotations will be uploaded to a backend server where the data is stored for training. The annotations remain in the user's history in case they want to edit it later.
